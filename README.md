# Фикс

**Ф**ильмы · **И**гры · **К**ниги · **С**ериалы — личный дневник того, что посмотрено, прочитано и пройдено.

## Как открыть

Откройте `index.html` в браузере, сборка не нужна.

- **Обычный режим** — ваши записи из `localStorage` (ключи `mediaDiary.entries.v1` и `mediaDiary.collections.v1`).
- **Демо** — `index.html?demo`: отдельное хранилище с примерами, настоящие записи не трогаются.

Шрифт заголовков — Soledago: положите файл в `fonts/` (см. `fonts/README.md`). Без него заголовки набираются Onest.

Поиск по каталогам: скопируйте `js/secrets.example.js` в `js/secrets.js` и впишите ключи. Файл в `.gitignore`. Без него приложение работает, Google Books ищет и без ключа.

## Устройство

Все модули лежат в общем пространстве `window.Diary` и подключаются по порядку в `index.html`.

| Слой | Файлы |
|---|---|
| Константы и помощники | `constants.js` (категории, статусы, жанры, цвета папок), `utils.js` |
| Данные | `storage.js` (адаптер localStorage), `repository.js` (записи, корзина, комментарии, цитаты), `collections-repository.js` (подборки), `demo-data.js` |
| Каталоги | `providers.js`, `provider-google-books.js`, `provider-tmdb.js`, `provider-rawg.js` |
| Интерфейс | `covers.js` (генератор обложек и талисманов), `stars.js` (оценка с половинками), `render.js` (карточки, фильтры, сортировка), `home.js` (папки), `category.js` (страница папки), `collections.js`, `trash.js`, `modal.js` (просмотр и редактирование записи) |
| Запуск | `state.js` (фильтры и текущая страница), `app.js` (маршруты `#/movie`, `#/collections`, `#/trash`, поиск, корзина) |

Интерфейс общается только с репозиториями, репозитории — только с адаптером хранилища. Чтобы перейти на синхронизацию, достаточно нового адаптера с тем же `load()`/`save()`.
