# Фикс

**Ф**ильмы · **И**гры · **К**ниги · **С**ериалы — личный дневник того, что посмотрено, прочитано и пройдено.

## Как открыть

Откройте `index.html` в браузере, сборка не нужна.

- **Обычный режим** — ваши записи из `localStorage` (ключи `mediaDiary.entries.v1` и `mediaDiary.collections.v1`).
- **Демо** — `index.html?demo`: отдельное хранилище с примерами, настоящие записи не трогаются.

Шрифт заголовков — Nauryz Red Keds, файл в `fonts/`.

Поиск по каталогам: скопируйте `js/secrets.example.js` в `js/secrets.js` и впишите ключи. Файл в `.gitignore`. Без него приложение работает, Google Books ищет и без ключа.

## Устройство

Все модули лежат в общем пространстве `window.Diary` и подключаются по порядку в `index.html`.

| Слой | Файлы |
|---|---|
| Константы и помощники | `constants.js` (категории, статусы, жанры, цвета папок и страниц), `utils.js`, `dialog.js` (окно подтверждения) |
| Данные | `storage.js` (адаптер localStorage), `repository.js` (записи, корзина, заметки, цитаты), `collections-repository.js` (подборки), `demo-data.js` |
| Каталоги | `providers.js`, `provider-google-books.js`, `provider-kinopoisk.js`, `provider-rawg.js` (`provider-tmdb.js` остался в папке, но не подключён — см. `docs/context.md`) |
| Интерфейс | `covers.js` (генератор обложек и фигур), `stars.js` (оценка с половинками), `pickers.js` (свои выпадающий список и календарь вместо нативных), `render.js` (карточки, фильтры, сортировка), `home.js` (полка папок и подборок), `category.js` (страница папки и язычки папок справа), `collections.js` (страница подборок), `trash.js` (корзина), `search.js` (результаты поиска), `about.js` (о приложении), `footer.js` (футер и переключатель дизайна), `modal.js` (просмотр и редактирование записи), `collection-modal.js` (окно подборки: название, состав, сохранение) |
| Резервные копии | `backup.js` (выгрузка и загрузка файла с записями и подборками, слияние по `id`) |
| Запуск | `state.js` (фильтры и текущая страница), `app.js` (маршруты, разделы в шапке, поиск в шапке, кнопка корзины) |

Интерфейс общается только с репозиториями, репозитории — только с адаптером хранилища. Чтобы перейти на синхронизацию, достаточно нового адаптера с тем же `load()`/`save()`.

## Навигация

- **Шапка — разделы сайта:** «Все фиксы» (главная, папки, корзина), «Подборки», «О приложении». Повторный клик по разделу возвращает к его началу.
- **Язычки справа — папки** внутри «Всех фиксов», язычок открытой папки выдвинут. На телефоне — ряд под шапкой.
- **Адреса:** `#/` главная, `#/movie`, `#/game`, `#/book`, `#/series`, `#/collections`, `#/trash`, `#/about`, `#/search?q=…`.
- **Поиск в шапке:** подсказки при вводе, Enter — страница со всеми результатами.
- **Корзина** — кнопка в правом нижнем углу со счётчиком.
