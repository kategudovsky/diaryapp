# Фикс

**Ф**ильмы · **И**гры · **К**ниги · **С**ериалы.

Прототип дизайна веб-приложения для личных коллекций фильмов, сериалов, книг и игр.

Структура — бумажные папки-разделители с язычками, стиль — яркая плоская графика с персонажами, бумага в клетку.

## Как открыть

Откройте `index.html` в браузере. `fiks.html` — та же страница, собранная в один файл, чтобы её было удобно переслать. Сборка не нужна: чистые HTML, CSS и JS.

## Что есть

- **Главная** — титульный лист и четыре вертикальные папки. При наведении папка раздвигается и показывает обложки, язычок справа ведёт внутрь.
- **Папка** — горизонтальные язычки статусов (Хочу / Смотрю·Читаю·Играю / Завершено / Брошено), поиск, сортировка, сетка карточек. Остальные папки — язычки у правого края.
- **Карточка** — лист в папке с кодом (`FILM_007 //`): статус, оценка, прогресс, даты, теги, заметки.
- **Добавление** и **глобальный поиск**.
- **Мобильная версия** — папки стопкой сверху вниз, язычки на разной высоте.

Обложки генерируются из названия (`js/covers.js`). Данные хранятся в `localStorage`, стартовый набор — в `js/data.js`.
