# Прототип «Свечение»

Развитие [пастельного минимализма](../pastel-minimal/) для будущего «стандартного» дизайна. Заливок нет: все поверхности белые, а цвет папки живёт в тонкой обводке, мягком цветном свечении и тени.

Скриншоты: [главная](home.png), [папка](folder.png), [язычки статусов](tabs.png), [окно записи](entry.png), [подборки](collections.png), [футер](footer.png).

## Цвета обводок и свечения

Пастельные тона стали насыщеннее, иначе тонкая линия на белом теряется.

| Где | Цвет |
|---|---|
| Фильмы | `#F084AE` |
| Игры | `#EDBE3A` |
| Книги, подборки | `#7D98EC` |
| Сериалы, корзина | `#A78BEA` |
| Поиск, статус «Хочу…» | `#6CC3D3` |
| Статус «Готово» | `#5DBE7A` |
| Статус «Заброшено» | `#8D90AB` |
| Текст и тёмные элементы | `#2B2A33`, второстепенный `#75737E` |
| Фон страницы | `#F7F6F3` |

## Как устроено

- Обводка 1,5 px цветом папки (`inset box-shadow`), вокруг — полупрозрачное кольцо 3–5 px и размытое свечение того же цвета.
- Фон страниц нейтральный, цвет папки — в обводке и свечении белого листа с карточками.
- Язычки статусов белые с обводкой цветом статуса; активный — обводкой папки, стыкуется с листом.
- Обложки: белый прямоугольник с тонкой цветной рамкой, свечением и точкой, название внизу.
- Плашки статусов, чипы и теги — белые с цветной обводкой; выбранный чип — с кольцом того же цвета.
- Кнопки белые с тёмной обводкой и лёгкой цветной тенью.
- Футер — светлый лист с нейтральной обводкой.
- Остальное как в пастельном минимализме: без фигур, клетки, наклонов, шрифт Onest.

Правила — в [overrides.css](overrides.css).
