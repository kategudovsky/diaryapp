# Прототип «Пастель, минимализм»

Второй, спокойный дизайн «Фикса». Будущий «стандартный» режим рядом с текущим «дофаминовым». Структура та же: титульный лист, вертикальные папки с язычками, язычки статусов, окно записи. Меняется только оформление.

Скриншоты сняты с настоящего приложения на демо-данных: [главная](home.png), [папка «Книги»](folder.png), [окно записи](entry.png).

## Палитра

| Роль | Дофаминовый | Пастель |
|---|---|---|
| Фильмы | `#EC1864` | `#F2E3E5` пыльная роза |
| Игры | `#FFC43D` | `#F3ECD9` сливочный |
| Книги | `#6077D4` | `#E1E5F2` бледный барвинок |
| Сериалы | `#B79CF2` | `#E9E3F3` туманный сиреневый |
| Фон страницы | `#DAF5F9` | `#FAF9F7` |
| Текст | `#1C1B3A` | `#2B2A33`, второстепенный `#75737E` |
| Кнопки | жёлтые | `#2B2A33`, текст белый |
| Звёзды оценки | жёлтые | `#2B2A33` |

Текст на папках везде тёмный (`#2B2A33`), в том числе на фильмах и книгах, где в дофаминовом он белый.

## Что убрано и упрощено

- Фигуры — на папках, в плитках статистики, у заголовка «фикс», в шапках страниц и пустых состояниях.
- Клетка на фоне и на листе с карточками, бумажное зерно.
- Наклоны, покачивания и вращения, рукописные подписи.
- Обложки: вместо узоров однотонный фон из пяти бледных тонов (`#F2E3E5`, `#F3ECD9`, `#E1E5F2`, `#E9E3F3`, `#EDEBE6`) и название внизу, Onest 600.
- Заголовки и логотип — Onest 600–700 вместо Nauryz, логотип «фикс» тёмный, без наклона.
- Расшифровка «Фильмы Игры Книги Сериалы» — простой строкой с жирными первыми буквами.
- Обводки 1 px вместо 2 px, кнопки и поля с радиусом 10 px вместо «таблеток», чипы — 8 px.
- Стикеры с итогами — прозрачные с тонкой рамкой.
- Комментарии — обычным шрифтом на белом, цитаты — с тонкой линией слева, без кавычки.

## Как собирался

Прототип — копия приложения, в которой заменены цвета в `js/constants.js`, `js/covers.js`, `js/stars.js` и добавлены правила из [overrides.css](overrides.css). При настоящей сборке тему лучше сделать отдельным набором переменных и настроек обложек, который включается переключателем в шапке.
